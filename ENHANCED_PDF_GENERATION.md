- **Main Title**: 20pt, Bold, Centered
- **Job Title**: 18pt, Bold, Centered
- **Section Headers**: 14pt, Bold, Underlined

#### Layout Features
- **Margins**: 50pt on all sides

- **Section Spacing**: 1 line break between sections
- **Bullet Points**: Professional bullet symbols (•)
- **Horizontal Line**: Blue accent line under main header

## Complete Job Data Integration

### 1. Job Details Section
```typescript
{
  position: string;           // Job title
  location: string;           // Job location
  jobType: string;           // full-time, part-time, contract, internship
  experienceLevel: string;   // entry, mid, senior, executive
  salary: number;            // Formatted with commas and currency
  postedDate: string;        // Current date when PDF is generated
}
```

### 2. Job Description Section
- **Source**: `job.description` field
- **Formatting**: Justified text with proper line spacing
- **Width**: 500px for optimal readability
- **Line Gap**: 2pt for comfortable reading

### 5. Benefits Section

## Data Handling and Fallbacks

### 1. Field Availability Checks
```typescript
// Safe field access with fallbacks
position: jobTitle || jobData.title || 'Not specified'
location: jobData.location || 'Not specified'
jobType: jobData.jobType || 'Full-time'
experienceLevel: jobData.experienceLevel || 'Mid-level'
salary: jobData.salary ? `$${jobData.salary.toLocaleString()}` : 'Competitive'
```

### 2. Conditional Section Rendering
- **Requirements**: Only shown if `requirements` array exists and has items
- **Skills**: Only shown if `skills` array exists and has items
- **Benefits**: Only shown if `benefits` array exists and has items
- **Company Info**: Only shown if `companyInfo` field exists
- **Salary Range**: Only shown if `salaryRange` object exists

### 3. Array Processing
```typescript
// Convert arrays to bullet points
jobData.requirements.map(req => ({ bullet: true, value: req }))
jobData.skills.map(skill => ({ bullet: true, value: skill }))
jobData.benefits.map(benefit => ({ bullet: true, value: benefit }))
```
